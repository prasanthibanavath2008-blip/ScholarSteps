# ScholarSteps
> **Find your opportunity. Prepare your next step.**

A premium scholarship discovery and application readiness platform created by **NextStep Rebels** under the theme *Learn, Grow and Connect*.

## Key Principles
- **Editorial Discovery meets Actionable Preparation**: Transparent criteria, source citations, document checklists, and task tracking.
- **Three-State Matching**: Rules evaluate to `PASS`, `FAIL`, or `UNKNOWN`. Missing answers never falsely pass.
- **Readiness != Eligibility**: Readiness scores represent self-reported preparation completion without claiming official legal eligibility or selection.
- **Privacy by Default**: In demo/guest mode, plans and answers stay stored in browser `localStorage`.

## Quick Start
```bash
# Install dependencies
npm install

# Run frontend development server
npm run dev

# Run domain unit tests
npm run test

# Build production bundle
npm run build
```
