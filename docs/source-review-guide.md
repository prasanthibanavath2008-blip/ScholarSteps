# Source Review & Provenance Guide

## Review Standards
1. **Primary Government/Institution Source Only**: We only link official state portals (e.g. `ssp.postmatric.karnataka.gov.in`, `scholarships.gov.in`, `mahadbt.maharashtra.gov.in`).
2. **Freshness States**:
   - `REVIEWED`: Verified within the last 90 days.
   - `REVIEW_DUE`: Over 90 days since last review or approaching cycle renewal.
   - `SOURCE_CHANGED`: Structural updates reported on the portal.
   - `LINK_UNAVAILABLE`: Official portal unreachable.
   - `UNVERIFIED`: Synthetic or draft fixture.
3. **No Automatic Verification Claims**: A live link does NOT mean application verified. Official rules must be confirmed on the external portal.
